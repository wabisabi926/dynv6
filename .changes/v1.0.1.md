新图标与移动端适配。

### 优化

- 全新应用图标：深蓝底 + 青色盾牌、镂空 d6 与两侧眉线，去掉小字与水印；重新导出 16 / 24 / 32 / 48 / 64 / 128 / 256 全套尺寸，飞牛、Windows 与网页共用同一套图标，小尺寸下主体更清晰。
- 移动端适配：
  - 宽度不超过 720px 时收窄页面留白、缩小标题，标签栏改为单行横向滑动；
  - 概览数值卡片改为自适应网格，设置项与快捷操作按钮改为单列或双列铺满；
  - 所有表格增加横向滚动容器，密钥、路径等长文本可换行，不再撑破布局；
  - 证书文件表在 600px 以下只保留文件名与下载按钮，按钮不再被挤出屏幕；
  - 输入框在 iOS 上使用 16px 字号，避免聚焦时页面被放大。

### 说明

- 本版本只更新界面与图标，配置、证书、管理员账号与调度逻辑不变，覆盖安装即可升级。
