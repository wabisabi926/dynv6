## 1.0.1

### 新增

- 应用图标重绘：深蓝底、青色盾牌与镂空 d6 标识，导出 16–256 px 全尺寸，飞牛、Windows 与 Web UI 共用。

### 优化

- Web UI 响应式布局：≤720 px 重排页面结构，标签栏与数据表格横向滚动，长路径与密钥自动折行。
- 证书列表在 ≤600 px 隐藏大小、修改时间与用途列，保留文件名与下载操作。
- 移动端输入框字号 16 px，抑制 iOS 聚焦缩放。

### 修复

- CSRF 校验兼容飞牛 App WebView：`Origin` 为 `null` 或缺失时改用 `X-Requested-With` 校验，修复 App 内保存配置返回 403。
- 反向代理改写 Host 且未透传 `X-Forwarded-Host` 时，回退至 `Sec-Fetch-Site` 同源判定。
- 新增请求来源校验单元测试，覆盖 WebView、同源、网关改写与跨站请求。
