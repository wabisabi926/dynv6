首个公开发布版本，包含 DDNS 自动更新、证书签发续期与证书分发完整链路。

### 新增

- 飞牛 fnOS 应用包：支持 x86_64 与 ARM64，通过应用中心手动安装，不申请 root 权限；使用飞牛官方 fnpack 1.2.1 打包，向导与配置字段通过官方校验。
- Windows 免安装单文件：双击运行，托盘右键「打开界面」，无需另装运行环境。
- Docker 部署：官方多架构镜像（amd64 / arm64），默认监听 `0.0.0.0:8092`，数据集中在 `/data`，首次访问创建管理员后使用；附 `docker-compose.yml`。
- 本地管理员账号：首次进入自动引导创建管理员，密码使用 PBKDF2-SHA256（120000 次迭代、随机盐）保存；支持登录、退出与修改密码，登录失败 5 次锁定 5 分钟。
- DDNS：支持 IPv4 / IPv6 与 IPv6 前缀更新，多探测源依次回退，可手动指定 IP；只有 IP 变化时才调用 dynv6 API。
- 证书：内置 acme.sh 与 dns_dynv6 插件走 DNS-01，支持泛域名、ECC 256/384 与 RSA 2048/4096，支持 Let's Encrypt 测试环境。
- 证书自检：签发后校验私钥匹配、SAN 覆盖、有效期与证书链，避免把坏证书分发给 Emby / Plex。
- 证书分发：可同时导出 PEM、Emby 使用的 PFX、Plex 使用的 P12，输出路径与文件名可自定义；分发失败自动重试。
- Telegram 通知：DDNS 更新、证书签发/续期、分发结果均可推送。
- 中转/代理环境适配：独立的 IPv4 / IPv6 探测地址，支持手动覆盖出口 IP。

### 修复

- Windows / 通用 Linux 独立运行默认监听 `127.0.0.1:8092`，开箱即可访问；飞牛版本固定使用 8092 端口，由飞牛网关反向代理，不需要开放端口或做端口映射。
- 修复 `DYNV6_SOCKET_GROUP` 只改权限不改属组的问题，并支持附加组校验，非 root 网关可正常连接。
- 修复 `admin.json` 损坏时被当成“未初始化”从而允许重新设置管理员的问题，现在会锁定并提示人工处理。
- 登录失败限流改为“账号 + 来源 IP”双维度，避免反向代理后一人输错锁死所有人。
- 修复合法目录名包含 `..`（如 `a..b`）被误判为路径穿越的问题。
- 修复备份目录无限增长，只保留最近 10 份。
- 允许把 DNS 生效等待设置为 0；下载接口只允许证书与私钥类文件。

### 安全

- 飞牛版本使用官方 `service_port=8092` 端口模式（与 faststrm 等第三方应用一致），由网关反向代理；Windows 本地访问增加一次性令牌、HttpOnly Cookie、Host / Origin 与 CSRF 校验。
- 私钥文件固定 0600，PFX/P12 与证书 0644；配置文件原子写入，避免半写损坏。
- 测试环境（staging）证书默认不向 Emby / Plex 分发，需要显式勾选才允许。
- 日志自动轮转，外部命令超时可取消，任务异常不会拖垮进程。

### 说明

- 飞牛网关管理员通过网关入口访问时免登录；直连地址与非管理员首次进入需创建本地管理员账号。
- 升级覆盖安装不会删除已有配置与证书；忘记管理员密码可停止程序后删除数据目录下的 `admin.json` 重新初始化。
- 本版本未附带任何本地配置、管理员密码、证书私钥或日志，首次使用需在界面中填写自己的 dynv6 Token 与邮箱。
