## 1.0.2

### 安全

- **H-01 修复**：移除对网关注入头 `X-Trim-Username` / `X-Trim-Isadmin` 的权限信任。服务模式（Docker / 飞牛网关 / 反向代理）统一要求本地管理员会话（PBKDF2-SHA256），网关身份仅作界面展示，伪造请求头不再能获取管理员权限。
- **M-02 修复**：服务模式首次初始化引入一次性 setup token（启动日志与数据目录 `setup-token` 各存一份，0600），初始化成功后自动删除；失败尝试纳入登录限流（账号 + IP 双维度），阻断未初始化实例被抢注。
- **M-03 修复**：移除 `DYNV6_AUTH_DISABLED` 环境变量后门，鉴权不再可被环境变量关闭。
- **M-04 修复**：IP 探测源固定为内置 4 个公共服务地址，移除自定义探测 URL 配置项，消除 SSRF 攻击面；探测客户端禁用重定向跟随。
- **M-05 缓解**：证书默认输出目录由共享目录调整为应用私有数据目录（`${APPDATA}/certs`），私钥不再落入 SMB/WebDAV 可见路径。
- **M-01 修复**：Docker 镜像以固定 UID 10001 非 root 运行；compose 默认仅绑定 `127.0.0.1:8092` 并限制日志体积。
- **L-06 加固**：主输出的私钥（`.key`）与 PFX/P12 强制 `0600`，不受 `file_mode` 配置影响。
- **L-08 修复**：Telegram 通知协程增加 `recover`，异常不再影响主服务。
- **L-02 加固**：Telegram 代理地址仅接受 `http/https/socks5/socks5h` 协议，保存时校验。
- **S-04 加固**：全站响应增加 `Content-Security-Policy`（`object-src 'none'`、`base-uri`/`form-action` 收敛）。
- 依赖治理：`golang.org/x/net` 升级至 v0.60.0，Go 工具链固定 1.26.10；`govulncheck` 纳入 CI 校验阶段（当前扫描 0 命中）。
- 供应链：GitHub Actions 全部固定至 commit SHA；fnpack 下载增加 SHA256 校验；Release 附 cosign keyless 签名（`SHA256SUMS.txt.sigstore.json`）。

### 新增

- 任务取消可中断 ACME DNS 生效等待，不再等到 `dns_sleep` 超时。
- `_acme-challenge` TXT 记录持久化登记：进程异常退出后，下次启动自动清理超过 1 小时的残留记录。

### 变更

- 前端移除「IPv4/IPv6 探测地址」配置项（内置源固定）；多出口环境请使用「手动指定 IP」。
- 首次部署交互：所有形态首次打开均需创建管理员账号；服务模式额外输入初始化令牌。
