概述

      
本应用承担两项职责：以动态 DNS（DDNS）维护 dynv6 zone 的 A/AAAA 记录；以 ACME DNS-01 挑战向 Let's Encrypt 签发证书，并在到期前自动续期、转换格式并分发。


      
接入步骤

      
    
        
  1. 在 dynv6 控制台 Keys → HTTP Tokens 获取账户级 HTTP Token。DDNS 更新（Update API）与 DNS-01 记录管理（REST v2）共用同一凭据。
    2. 
        
  2. 「设置」中填写注册域名（zone）与 HTTP Token，保存。
    3. 
        
  3. 建议先以 staging 环境完成首次签发验证链路，再切回生产（production）环境，规避 CA 速率限制（rate limit）。staging 证书默认不分发。
    4. 
        
  4. 签发成功后，在「设置 → 分发目标」为 Emby / Plex 配置目标目录。
    5. 
      


      
部署形态与监听

      
    
        
  • 飞牛 fnOS：固定 8092 端口，由统一网关反向代理（reverse proxy），无需端口映射。网关注入的身份仅用于界面显示，权限以本地管理员会话为准。
    • 
        
  • Windows / 通用 Linux：默认绑定 127.0.0.1:8092，由一次性访问令牌（local token）+ Host 校验保护，请从托盘进入界面。
    • 
        
  • Docker：容器监听 0.0.0.0:8092，compose 仅映射到宿主机回环；以固定 UID 10001 非 root 运行，宿主机挂载目录需 chown 10001:10001。公网部署必须置于 HTTPS 反向代理之后。
    • 
      


      
证书链路

      
内置 lego（纯 Go ACME 客户端），通过 dynv6 REST API 写入 _acme-challenge TXT 记录完成 DNS-01 验证，无需 sh / curl / openssl。证书机构仅提供 Let's Encrypt 生产与 staging；其他 CA 需要 EAB（External Account Binding）凭据，暂不支持。staging 证书默认仅导出，需显式启用「允许测试证书分发」才会覆盖目标文件。


      
密钥与凭据管理

      
    
        
  • 凭据（HTTP Token、TG Bot Token、密码）以 0600 落盘，接口仅返回 __KEEP__ 占位符，日志统一脱敏。
    • 
        
  • 主输出目录默认位于应用私有数据目录；私钥与 PFX/P12 强制 0600，分发目标文件为 0644（供其他服务读取）。
    • 
        
  • 分发前执行路径规范化（canonicalize）与越界（traversal）校验；自定义目录需在飞牛「应用设置 → 授权路径」中授权。
    • 
      


      
消费端配置

      
Emby：设置 → 网络 → 自定义 SSL 证书，指向分发后的 .pfx 绝对路径，密码与「PFX 密码」一致，安全连接模式建议「首选，但非必需」，保存后重启服务。

      
Plex：设置 → 网络（显示高级）→ Custom certificate location 填 .p12 绝对路径，Custom certificate encryption key 填 P12 密码，Custom certificate domain 必须与证书 CN/SAN 一致；保存后重启。PFX/P12 均以 AES-256-CBC + SHA256 导出，符合 Plex 1.32+ 的解析要求。

      
飞牛系统证书：本应用不写系统证书目录。如需复用，请在「系统设置 → 安全性 → SSL 证书」手动导入 fullchain.crt 与 .key，后续续期由本应用自动完成。


      
通知

      
通过 Telegram Bot API 推送 DDNS 更新、签发/续期、分发与转换结果；支持 HTTP/SOCKS5 代理与 HTML 转义正文。相同内容的重复通知在 10 分钟窗口内去重。


      
运维与故障定位

      
    
        
  • 调度：DDNS 默认 5 分钟，证书检查默认 12 小时（阈值 30 天）；任务按 lane 串行执行，DDNS 与证书互不阻塞。
    • 
        
  • 日志：界面展示环形缓冲最近 500 条（凭据已脱敏）；文件日志 dynv6.log 10 MB 轮转保留一份。
    • 
        
  • 签发实时输出阶段化日志（注册账户 → 创建 TXT → 等待生效 → 验证 → 导出 → 转换 → 分发）；支持取消运行中的任务，取消会中断 DNS 生效等待并删除已创建的 TXT 记录。
    • 
        
  • 进程异常退出后，下次启动自动清理超过 1 小时的残留 TXT 记录。
    • 
        
  • 证书机构切换（staging ↔ production）会自动强制重新签发，避免部署不受信任的 staging 证书。
    • 
      


      
管理员账号

      
所有部署形态首次进入需创建管理员账号；口令以 PBKDF2-SHA256（120,000 迭代）加盐存储，会话有效期 7 天。

      
    
        
  • 初始化令牌仅对「绕过网关的直连」来源强制：飞牛桌面图标经统一网关访问（回环来源）免令牌，直接创建账号；浏览器直接访问 NAS 的 IP:8092、Tailscale 等组网地址直连、以及 Docker 端口映射直连，均视为不可信来源、需要令牌（Docker 用 docker logs dynv6 | grep 初始化令牌 获取）。令牌在初始化成功后自动销毁。
    • 
        
  • 忘记口令：停止应用、删除数据目录 admin.json 后重启重新初始化；文件损坏时应用 fail-closed，锁定初始化以防接管。
    • 
        
  • 修改口令后全部会话立即失效。
