第一次使用

      
本应用同时做两件事：检测公网 IP 变化并更新 dynv6 的 DDNS 记录，以及在 Let's Encrypt 证书到期前自动续签、转换并分发。

      
    
        
  1. 登录 dynv6.com，点击右上角账号 → Keys → HTTP Tokens，复制那串 Token。DDNS 更新和证书签发共用这一个 HTTP Token，不需要两个。
    2. 
        
  2. 在「设置」填写域名与 HTTP Token（邮箱可选），确认输出目录后保存。
    3. 
        
  3. 建议先把证书机构切到 测试环境（staging） 点一次「立即签发」验证流程，成功后再切回正式环境，避免触发速率限制。测试证书默认只导出，不会分发到 Emby/Plex。
    4. 
        
  4. 签发成功后到「证书文件」查看 6 个文件，再到「设置 → 分发目标」配置 Emby / Plex 的目录。
    5. 
      

      
路径与授权（飞牛 / Windows / Docker）

      
飞牛应用默认只能访问自己的数据目录、临时目录和声明的共享目录，不能直接写用户的其他文件夹。如果分发目标不在默认共享目录里，请先到飞牛「应用设置 → 授权路径」把目标目录授权给本应用；应用概览页会列出已授权的路径，并在路径不可写时提示。

      
    
        
  • 飞牛：保持 ${APPDATA} / ${SHARE} 等变量写法即可，平台会自动替换。
    • 
        
  • Windows：双击运行即是正式模式，DDNS 更新、分发与定时任务都会真实执行；配置保存在 %LOCALAPPDATA%\dynv6。本地界面使用一次性令牌保护，请从托盘「打开界面」进入，不要直接访问裸地址。证书签发/转换需要 Git for Windows（自带 sh 和 openssl），装好后重启应用会自动识别；没装也不影响 DDNS 与分发。
    • 
        
  • Docker：设置 DYNV6_OUTPUT_DIR 等环境变量并挂载卷，或直接填容器内路径。
    • 
      

      
关于证书机构

      
这里只提供 Let's Encrypt 正式 与 staging 测试 两种：两者都在内置 acme.sh 的 CA 别名表中，配合 dns_dynv6 插件用现有 Token 即可签发，不需要额外凭据。测试证书默认只导出到主输出目录，不会分发到 Emby/Plex；只有显式勾选「允许把测试证书分发到 Emby / Plex」才会覆盖目标文件。ZeroSSL / SSL.com / Google 需要 EAB 外部账户绑定凭据，Buypass 已不在当前 acme.sh 的支持列表里，因此不提供这些选项。

      
飞牛系统自身的 SSL 证书

      
本应用不会自动写入系统证书目录（该目录与数据库结构属于飞牛内部实现，升级易失效）。如需让飞牛后台也用这张证书：进入「系统设置 → 安全性 → SSL 证书 → 新增证书」，证书文件选 fullchain.crt，私钥选 .key，手动上传一次即可。之后每 90 天的续期、格式转换、分发由本应用自动完成。

      
Emby

      
Emby 后台 → 设置 → 网络（或高级）→ 自定义 SSL 证书：证书路径填分发后的 .pfx 绝对路径，证书密码填「设置」里的 PFX 密码；安全连接模式选「首选，但非必需」；保存后重启 Emby。生成的 PFX 包含站点证书与中间链，已用 .NET 的 X509Certificate2 实测可加载。

      
Plex

      
Plex 后台 → 设置 → 网络 → 显示高级 → Custom certificate location 填 .p12 绝对路径，Custom certificate encryption key 填 P12 密码，Custom certificate domain 填你的域名（必须与证书里的域名一致）；保存并重启 Plex。生成的 p12 已强制使用 AES-256-CBC / SHA256，符合 Plex 1.32+ 的要求。

      
安全说明

      
    
        
  • 应用以专用包用户运行，不申请 root，不修改系统定时任务，不改动飞牛系统目录。
    • 
        
  • Token、邮箱、密码保存在 0600 权限的配置文件中，接口不回显，日志自动脱敏。
    • 
        
  • 飞牛版本固定使用 6010 端口，由飞牛网关反向代理，不需要开放端口或做端口映射；Docker 用 DYNV6_DOCKER=1 或 DYNV6_LISTEN 监听所有网卡。
    • 
        
  • Windows / 通用 Linux 独立运行时默认监听 127.0.0.1:6010，使用一次性令牌 + Host/Origin 校验；Windows 请从托盘打开，不要直接访问裸端口。
    • 
        
  • Docker 部署默认监听 0.0.0.0:6010（DYNV6_DOCKER=1 或 DYNV6_LISTEN），通过映射端口访问，所有 API 都需要先登录管理员账号；公网访问建议在容器前加 HTTPS 反向代理。
    • 
        
  • 自定义路径请指向已授权目录；分发前会做路径规范化与越界检查。
    • 
        
  • 主输出默认 0600；分发的 PEM 私钥固定 0600，PFX/P12 与证书 0644。
    • 
      

      
管理员账号

      
首次在 Windows / Docker / 通用 Linux 上打开界面时，会先进入初始化页面创建管理员用户名和密码。密码使用 PBKDF2-SHA256 加盐保存，不保存明文；登录后 7 天内有效。

      
    
        
  • 飞牛环境由统一网关注入身份，不需要本地管理员账号；应用本身固定监听 6010 端口，由网关反向代理。本地账号主要用于 Windows / Docker / 通用 Linux（默认 6010 端口）。
    • 
        
  • 忘记密码：停止应用，删除数据目录下的 admin.json，重启后重新初始化。删除前请确认没有其他地方使用同一份数据目录。
    • 
        
  • 如果 admin.json 损坏或不可读，应用会锁定初始化并提示删除该文件，避免被他人重新接管。
    • 
        
  • 设置页「管理员账号」可以修改密码；修改后旧会话会全部失效，需要重新登录。
    • 
        
  • 如需临时关闭本地管理员鉴权，可设置 DYNV6_AUTH_DISABLED=1，仅建议在完全受信任的本机调试时使用。
